# SkillTrack AI

AI-powered platform for tracking employment outcomes,
skill gaps, and the impact of skilling initiatives.

## Features

- Trainee tracking
- Employment outcome tracking
- Employment prediction
- Retention prediction
- Skill-gap analysis
- Training provider analytics
- District-level analytics
- Government impact dashboard

### Backend
